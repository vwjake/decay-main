Public pages

Landing page with upcoming events, merch, media and newsletter sign-up.

About Migrated

Mission, five stated goals, founding story, and the six-member board of directors.

Support & Donate Migrated

Two pages on the old site, merged into one: Givebutter, Patreon, postal donations, and the funder/partner logos.

Policies Migrated

Safer space policy, prohibited behaviours, and the concerns@ reporting address.

Get Involved Partial

The volunteering explainer and perks are folded into Support; the forms it links to are not built.

Groups hub + five group pages Not yet

Open Draw, No Tape, Decentralized Tech, Movie Club, Mutual Aid. Full written copy, section blocks and hero images already sit in site-content.json.

Community links Not yet

52 curated links to other Olympia organisations, editable from the admin panel.

Contact Not yet

Message form with CSRF token, arithmetic captcha, honeypot field and email delivery. Needs a mail path before it can move.

Public user profiles Not yet

Per-person page driven by the user records.

Custom 404 Not yet

Events & calendar

The heart of the old site, and the part most fully rebuilt. The unmigrated items are mostly operational record-keeping.

Month calendar grid Migrated

Week-per-row grid with previous/next month navigation and events stacked per day.

List view & archive Migrated

Chronological upcoming list plus the full past-events archive, both paginated.

Event detail page Migrated

Per-event page with flyer, description, times and open volunteer roles.

Flyer upload Migrated

Per-event image with generated web-sized copies. Replaces the old thumbnail pipeline.

Categories & programs Migrated

Hand-typed categories normalised into event types; recurring programs preserved as types.

Quarterly archive rollover Migrated

The old site moved finished quarters into dated folders. One table now holds all 676 events; the split is a query, not a filesystem move.

Volunteer slots per event Partial

Door, sound, cleanup and promote roles carry over and the public page shows what's open. Nobody can sign up yet.

Printable calendar Not yet

Print-optimised month sheet for putting on the wall.

RSS event feed Not yet

"Decay DIY Shows" RSS at a fixed URL. The rewrite publishes iCalendar instead, which is a different audience.

Day view Not yet

Everything scheduled on one date, events and meetings together.

Recurring events Not yet

Pattern, until-date and explicit date list. The fields exist in the old records but were unused — every weekly event is a separate file.

Event duplication Not yet

Copy an event as the basis for the next one — the practical workaround for no recurrence.

Bulk delete Not yet

Select and remove many events at once.

Keyholder assignment Not yet

Two keyholder slots per event, naming who opens and closes the building.

Event financials Not yet

Door gross, concessions, merch sales, artist pay, donations, expenses and net, recorded per event.

Post-event reports Not yet

Actual attendance, who filed it, and a written summary.

Grant reporting fields Not yet

Youth participation and youth-organised percentages, artists engaged, accessibility notes, funder logo presence, community benefit. This is what the Inspire grant is reported against.

Event schema validation Not yet

Records checked against schema.json on save. The rewrite gets much of this from the database's own column types.

Intake & forms

Everything the public can submit. None of it has moved — each needs a decision about where the data lands.

Event booking request Not yet

"Host an event at DECAY" form capturing organiser, contact, date, bill, attendance estimate and needs.

Booking request queue Not yet

Admin review, edit and approval, turning an accepted request into a calendar event. 19 live requests, 217 records in total.

Impact survey Not yet

Nine questions on safety, diversity, connection, gaps and volunteering interest, with a results dashboard. Grant-facing.

Diversity survey Not yet

Demographic collection with separate internal and public-facing variants and two results views.

Bio survey Not yet

Name, pronouns, role and biography, collected for people involved with the space.

Spam defences Not yet

CSRF tokens, a hidden honeypot field and an arithmetic captcha, applied across every public form.

Volunteer shift form Dropped

Booked a specific shift in advance. Parked for now — when it returns it's a fill-in form, not a registry.

Volunteer list sign-up Dropped

Joined a call-list for occasional help. Replaced by the newsletter.

Volunteer directory Dropped

Names, emails, phone numbers and availability in a TSV plus JSON. Deliberately not carried over — the rewrite stores no volunteer contact details at all.

The day-to-day panel. The rewrite covers publishing; the old site also ran the organisation from here.

Dashboard Migrated

Rebuilt to lead with what needs attention rather than a list of links.

Event management Migrated

Create, edit, delete, flyer upload and volunteer roles, with a paginated table.

Blog Migrated

New in the rewrite — the old site had no blog. Drafts, publish and unpublish.

Shop catalogue Migrated

New in the rewrite. Imported from the shop export; display only, orders stay on shop.decay.events.

Photo gallery Migrated

New in the rewrite. Upload with captions and generated web-sized copies.

Meetings calendar Not yet

A second calendar for board and organising meetings, optionally anonymised on the public grid. 76 records.

Standard operating procedures Not yet

21 written procedures — event booking, closing, promo, board onboarding, expense reimbursement, grant process, digital security — each with its own feedback thread.

Reminders Not yet

Dated notes surfaced on the calendar as badges.

Site content editor Not yet

Edits the copy behind the groups pages without a deploy. The rewrite's prose pages are currently in templates.

Community links editor Not yet

Curates the 52-entry local links directory.

Activity log Not yet

Append-only audit trail of admin actions, written as JSON lines and browsable in the panel.

Admin — people & access

The old site modelled real roles at the space. The rewrite has accounts and permissions, but only one role defined so far.

Login & sessions Migrated

Per-account sign-in with hashed passwords and server-side session checks on every request.

Roles & capabilities Partial

The old model had three roles — Mega Admin, Admin and Agent (keyholder) — over capabilities like events.manage, events.manage_own, volunteers.assign and events.book. The rewrite checks permissions the same way but defines only master.

User accounts Partial

Create, edit, set password and delete all work. The old site's 29 user records, with their roles and history, have not been imported.

Password reset by email Not yet

Forgot-password and reset flow, with attempt throttling recorded to disk. Currently an admin sets a new password directly.

Invite-token sign-up Not yet

Single-use links that let someone create their own account at a chosen role, instead of an admin typing a password for them.

Keyholder sign-up Not yet

Token-gated onboarding specifically for keyholders.

Key tracker Not yet

Who physically holds which key to the building, and when it changed hands. The single largest admin page on the old site.

Volunteer hours Not yet

Hours tracked per person per event — the basis of the free-entry perk and of grant reporting.

Retire a user Not yet

Deactivates an account while keeping its history, rather than deleting it.

Welcome email Not yet

Sends new people their orientation message from the panel.

Volunteer records Dropped

24 volunteer profiles with contact details, promoted from user records. Parked along with the rest of the volunteer system.

Integrations

Outside services the old site talks to. Two are heavily wired in; the rest are links.

Calendar subscription Migrated

The old site pushed events into Nextcloud over CalDAV with stored credentials. The rewrite publishes a feed that Nextcloud and phones subscribe to instead — read-only, no credentials, and event identities are preserved so nothing duplicates.

Newsletter, donations & socials Migrated

beehiiv, Givebutter, Patreon, Instagram, Discord and YouTube, all linked. Twitch is deliberately not — the account isn't used.

Discord announcements Not yet

Webhook posts to the server when events are created or changed.

Discord scheduled events Not yet

Creates a matching scheduled event inside Discord so members see it in the server's own events list.

Outbound email Not yet

Contact replies, welcome messages and password resets all depend on this. Nothing in the rewrite sends mail yet.

Text to speech Not yet

Generates spoken audio from typed text — used for announcements in the space.

Platform & housekeeping

Infrastructure. Several items are answered by the rewrite's architecture rather than reimplemented.

Data storage Migrated

Flat JSON files, one per record, replaced by SQLite. Removes the hand-rolled load/save/lock helpers entirely.

Image handling Migrated

Upload validation by extension and content sniffing, plus generated web-sized copies in place of the old thumbnail script.

Response caching Migrated

The old site cached parsed JSON to PHP files for events, meetings, reminders, requests and users. A compiled binary querying SQLite doesn't need the layer.

Server health monitor Not yet

Checks disk, memory, PHP error log and data integrity, with a dashboard and a scheduled runner.

Broken link checker Not yet

Crawls the site and reports links that no longer resolve.

Subdomain checker Not yet

Confirms subdomains still resolve and respond.

Markdown rendering Not yet

Blog bodies are stored as Markdown but currently rendered as plain paragraphs.
